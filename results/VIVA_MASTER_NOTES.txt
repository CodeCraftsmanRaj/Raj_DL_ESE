Global implementation pattern used in all files:
1) Create/load dataset (subset/synthetic/professional text corpus)
2) Define model class using torch.nn.Module
3) Train with Adam + proper loss function
4) Evaluate with model.eval() + torch.no_grad()
5) Save figure in results/ with experiment label

FAST VIVA CHANGE GUIDE (what to edit quickly during questioning)
1) Change dataset size:
- In MNIST scripts, adjust subset slicing counts near dataset creation.

2) Change model capacity:
- Edit hidden units/channels in class __init__ definitions.

3) Change optimizer behavior:
- Edit learning rate in optim.Adam(..., lr=...)
- Optionally switch optimizer to SGD to explain convergence differences.

4) Change training budget:
- Edit epochs in train_model calls.

5) Change sequence difficulty (RNN/LSTM/GRU):
- Edit seq_length list (e.g., [10,20,40,80]) and corpus size in data.txt.

6) If asked why one run differs from another:
- Explain stochastic training: random initialization, mini-batch sampling, and hardware backend variation.
